# Admin Playbook — Junior → Senior

You are Junior Admin now and expected to lead as Senior Admin next year.  
This file is about **how to decide and run**, not the website.

---

## 1. Your job in one sentence

Make ICON feel organized, energetic, and fair — so participants remember the fest, not the chaos.

---

## 2. Decision framework (use every time)

For any idea (theme, new event, sponsor, budget ask), answer:

1. **Does it fit the theme / ICON identity?**  
2. **Do we have a named owner?** (If no owner → no event.)  
3. **Do we have venue + time that doesn’t clash with hackathon?**  
4. **What’s the minimum quality bar?** (Better skip than half-run.)  
5. **What’s the rollback?** (If rain / lab locked / low registration.)

If 2 answers are “no,” park the idea.

---

## 3. Org chart you should build early

```
Senior Admin (you next year)
├── Technical Ops (hackathon + lab events)
├── Experience Ops (gallery + tech fair + treasure hunt)
├── Sports & Gaming
├── Design & Content
├── Registration & Data
├── Hospitality & Logistics
└── Sponsors & Finance
```

Even if one person wears two hats, **write the hat name**. Accountability > vibes.

## 6. Meeting with seniors — what to present

Bring **one page**, not a novel:

1. Top 3 themes + your recommendation  
2. Must-keep events vs proposed new events (max 3 new)  
3. Day 1 / Day 2 sketch (no need for perfect times yet)  
4. Risks (venue, volunteers, budget)  
5. Ask: “Approve theme + event spine this week?”

---

## 7. Quality bars (steal these)

### Hackathon
- Instructions sheet printed + digital  
- Mentors schedule (who is in room when)  
- Judging rubric shared before coding ends  
- Backup power / extension boards listed  

### Tech Fair
- Every stall has: game rules card, prize stock, one volunteer  
- Opening time honored (don’t open 40 mins late)  

### Gallery
- Numbered booths, nameplates, jury form  
- People’s Choice voting closes before valedictory  

### Sports
- Fixture sheet night before  
- Water + first-aid visible  

---

## 8. Common failure modes (avoid these)

| Failure | Prevention |
|---------|------------|
| Too many events, empty rooms | Cap events to owner capacity |
| Theme decided late | Lock 60–90 days prior |
| Only 3 people know the plan | Shared run sheet + group |
| Registration mess | Test QR / form 7 days before |
| Winners not ready at ceremony | Collect results 45 mins early |
| Volunteers ghost on Day 1 | Confirm roster night before + backup list |

---

## 9. Personal growth track (you)

As Junior Admin this cycle:
- Own **one vertical completely** (e.g. Tech Fair or Registration).  
- Shadow seniors on budget + faculty emails.  
- After fest: write a 1-page “What I will change next year.”

As Senior Admin next cycle:
- Decide theme early.  
- Delegate; don’t run every stall yourself.  
- Protect the hackathon — it’s the reputation event.

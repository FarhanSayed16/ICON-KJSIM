# Tech Fair Mini-Games + Bottle Events

For **Event Heads** and Admin.  
Use with the Team Brief (`05_TEAM_BRIEF_45_DAYS.md`).

**Policy for Tech Fair rewards:**  
Prefer **gift hampers / goodies** (snacks + stickers + small merch + coupons), **not cash prizes**.

---

## A) Tech Fair — what it should feel like

Walk-in. Fast rounds (1–3 minutes). Instant winner feeling. Loud amphitheatre energy.  
Target: **6–8 stalls max** (better 6 excellent than 12 empty).

Each stall must define:
1. Game name (theme-linked after theme lock)  
2. 1-line how to play  
3. Time per attempt  
4. What you need (table, laptop, printouts, props)  
5. 1 volunteer minimum  
6. Reward tier (stamp / small hamper / big hamper)

---

## B) Mini-game ideas (pick 6–8)

### High energy / crowd favourites
| Game | How it works | Needs | Why it works |
|------|--------------|-------|--------------|
| **Type Racer** | Fastest WPM in 60s | 1–2 laptops | Instant competition |
| **Trivia Wheel** | Spin → answer tech/fun Q | Wheel / bottle + Q cards | Loud + fair |
| **Logo Rush** | Guess startup/app logos | Print deck / slides | Non-tech friendly |
| **Emoji Decode** | Guess movie/tech from emojis | Cards | Fast laughs |
| **Paper Plane Accuracy** | Fold + hit target | Paper + target | Zero tech, high fun |
| **Balloon Pop Quiz** | Pop balloon → question inside | Balloons + Q slips | Visual chaos (good) |

### Tech / skill (still fun)
| Game | How it works | Needs | Why it works |
|------|--------------|-------|--------------|
| **Bug Squash** | Find bugs in 6–10 lines | Printed snippets | Feels “ICON” |
| **Prompt Duel** | Best funny/useful AI prompt in 90s | Phone/laptop + judge | Very current |
| **Memory Grid** | Repeat sequence of lights/cards | Cards / phone app | Brain vs speed |
| **Pseudo-Code Scramble** | Arrange steps in order | Card strips | Easy to run |
| **UI Hotseat** | Fix a bad screen in 3 mins (paper) | Printed ugly UI | Creative crowd |
| **Cable Chaos** | Untangle / connect correctly timed | Old cables / labeled ports | Physical + tech |

### Duo / social
| Game | How it works | Needs |
|------|--------------|-------|
| **Blind Draw Instruct** | One describes icon, one draws | Paper |
| **Human Circuit** | Team holds “circuit” poses / pass object without break | Soft props |
| **Two Truths 1 Bug** | Guess the fake tech fact | Host |

### Innovative / memorable (if you have 1 strong volunteer)
| Game | How it works | Notes |
|------|--------------|-------|
| **QR Treasure Micro** | 3 QR around amphitheatre → final word | Needs prep night before |
| **AR / Filter Pose** | Pose with fest IG filter | Needs phone + printed frame |
| **Build-a-Meme** | Caption a template in 60s | Project funny ones |
| **Reaction Time Pad** | First to slap correct colour/answer | DIY pads / buzzers |

## D) Gift hamper plan (no cash)

### Stamp / passport system (recommended)
- Play a stall → get a stamp.  
- **3 stamps** = sticker / candy pack  
- **5 stamps** = small hamper  
- **All stalls** = bigger hamper + shoutout  

### Hamper tiers (examples)
| Tier | What’s inside (examples) | When |
|------|--------------------------|------|
| **Micro** | Candy + ICON sticker | Instant small wins |
| **Small** | Snacks + pen/keychain + stickers | Stall champions / 5 stamps |
| **Prime** | Snacks + small merch + coupon + handwritten note | Fair MVP / all stamps |
| **Booth Champion** | Slightly bigger mini-hamper | Top score at each stall (optional) |

### Sourcing tips
- Local snacks bulk pack  
- College print stickers (cheap + brand)  
- Sponsor coupons (cafe / bookstore)  
- Reuse leftover merch as hamper fillers  

**Budget rule:** decide **₹ per visitor average** first, then build hamper contents backward.

## E) Bottle events (backup / fill-gap events)

**Bottle event =** ready-to-open event if:
- A main event has low registration  
- Venue fails / rain  
- A time slot opens  
- Tech Fair needs extra stall  
- Day 2 afternoon feels empty  

### Rules for bottle events
- Setup under **30–45 mins**  
- Needs **1–2 volunteers only**  
- No heavy equipment  
- Rules fit on **half a page**  
- Can run without theme reprint (or use generic “ICON Arena” card)

### Bottle event ideas
| Bottle event | Format | When to open |
|--------------|--------|--------------|
| **Lightning Quiz** | 20-min rapid quiz | Spare seminar slot |
| **One-Minute Pitch** | 60s idea pitch | Gallery lull |
| **Sketch-the-Problem** | Draw a solution poster | Creative crowd free |
| **Chess Blitz Board** | 5+0 casual boards | Chess ends early |
| **FIFA Friendlies** | Open challenger queue | Between FIFA rounds |
| **Photo Challenge** | Theme selfie + caption | Whole campus |
| **Debug Dash Mini** | 15-min bug hunt | Lab free |
| **Prompt Roulette** | Random prompt bowl | AI interest |
| **Paper Prototype Relay** | Team of 3, 8 mins | Fair overflow |
| **Open Mic 3** | 3 speakers × 5 mins | Closing filler |
| **Human Bingo** | Find people who… | Icebreaker morning |
| **Speed Mentoring** | 5-min mentor rounds | If seniors available |

### Recommended bottle pack (keep ready)
1. Lightning Quiz  
2. One-Minute Pitch  
3. FIFA Friendlies queue  
4. Photo Challenge  
5. Prompt Roulette  

Event heads: each vertical should own **at least 1 bottle event**.

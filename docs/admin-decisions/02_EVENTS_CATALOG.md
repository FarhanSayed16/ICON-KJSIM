# Events — Keep This Year vs Extra Edition

Two lists only (as requested):

1. **KEEP THIS YEAR** — core spine from seniors + safe runs  
2. **EXTRA EDITION** — add-ons / different things you can plan if capacity allows  

---

# 1) KEEP THIS YEAR (core)

These should almost definitely happen. This is the ICON spine seniors already described.

## A. Flagship technical
| Event | Format | Why keep |
|-------|--------|----------|
| **CodeIcon (Hackathon)** | Teams, full day (Day 1) | **Mandatory.** Main reputation event. |

## B. Showcase
| Event | Format | Why keep |
|-------|--------|----------|
| **ICON Gallery** | Project stalls + jury | Students show real work; strong for faculty & Instagram. |

## C. Tech Fair (mandatory fun zone)
| Event | Format | Why keep |
|-------|--------|----------|
| **Tech Fair** | Walk-in mini games + prizes | High footfall, amphitheatre energy, open for everyone. |

### Tech Fair mini-games to KEEP (simple, proven)
| Mini-game | What players do |
|-----------|-----------------|
| Bug Squash | Find bugs in short code snippets |
| Type Racer | Fastest typing wins |
| Tech Trivia Wheel | Spin + answer → instant prize |
| Logo / Startup Guess | Non-tech friendly |
| Memory Grid / Sequence | Quick brain game |
| Paper Prototype (5 min) | Draw a screen for a prompt |

*(6 stalls is enough. Quality > quantity.)*

# 2) EXTRA EDITION (new / different things you can plan)

Only add these if you have **owner + venue + volunteers**.  
Pick **2–4 max** for a strong year. Don’t add all.

## A. Extra technical events
| Event | Format | Why it’s good | Effort |
|-------|--------|---------------|--------|
| **Prompt Wars (AI)** | Solo/duo timed prompts | Very current; DST fit | Medium |
| **Web Dev Showdown** | Build a site in 2–3 hrs | Portfolio value | Medium |
| **UI/UX Sprint** | Figma redesign challenge | Design crowd | Low–Med |
| **Data Dash** | Dataset → insight in 2 hrs | Perfect for Data Science dept | Medium |
| **Blind Coding** | Code with limited output view | Fun lab filler | Low |
| **CTF Lite** | Mini cybersecurity flags | “Pro” techfest feel | High |
| **Pitch Perfect** | 3-min tech pitch | Gallery companion | Low |
| **API Heist** | Build a tool using public APIs | Practical skills | Medium |
| **IoT Mini Hack** | Sensors / hardware | Wow factor | High (kits needed) |

## B. Extra gaming
| Event | Format | Notes |
|-------|--------|-------|
| **BGMI** | Squads / custom room | Huge participation if managed well |
| **Valorant / PC esports** | 5v5 | Only if PCs + fair-play staff |
| **FIFA Pro bracket + Casual bracket** | Split skill levels | More players, less rage |
| **Chess Blitz night** | Ultra-fast boards | Evening filler |

## C. Extra sports / physical
| Event | Notes |
|-------|--------|
| **Table Tennis** | Easy backup sport |
| **Carrom** | Indoor, low cost |
| **Relay / Arena games** | Short amphitheatre challenges during Tech Fair |
| **E-sports + Physical hybrid** | e.g. FIFA loser plays a fun physical forfeit game (light, optional) |

## D. Extra experience / “different” ICON ideas
| Idea | What it is | Why plan it |
|------|------------|-------------|
| **ICON Night / Open Mic Lite** | Music + tech talks (short) | Closes Day 1 energy |
| **Alumni / Industry 20-min Talk** | 1–2 speakers | Faculty love it; adds prestige |
| **People’s Choice Gallery Vote** | QR voting | Extra engagement without new event |
| **Theme Escape Room** | Classroom timed escape | High wow; needs design crew |
| **Startup Story Corner** | Senior students share failed/successful builds | Low cost, high value |
| **Campus Mural / Live Design Wall** | Live poster / graffiti tech art | Content machine for socials |
| **ICON Passport** | Stamp card across stalls | Increases Tech Fair completion |
| **Charity / Social Impact Track** in Gallery | Separate prize | Stronger story for institute |
| **Inter-college invite slots** | Limited external teams | Makes fest feel bigger |
| **Merch drop + Theme photobooth** | Not an event, but “edition” feel | Memory + branding |

## E. “Edition names” you can market (packaging)

You don’t always need new games — sometimes you package upgrades as an edition:

| Edition label | What changes |
|---------------|--------------|
| **ICON: Classic** | Only the KEEP list |
| **ICON: AI Edition** | Keep list + Prompt Wars + AI stalls in Tech Fair |
| **ICON: Swarajya / Chakravyuh Edition** | Same events, theme-skinned clues, decor, treasure hunt |
| **ICON: Arena Edition** | Stronger sports + FIFA + optional BGMI |
| **ICON: Builders Edition** | Gallery + Pitch + Hackathon spotlight |

Pick one edition story for posters.

# Suggested mixes (easy decisions)

### Mix A — Safe year (recommended if team is small)
**Keep all core.**  
Extra: none, OR only **Prompt Wars** + **People’s Choice vote**.

### Mix B — Strong growth year (recommended)
**Keep all core.**  
Extra:
1. Prompt Wars (AI)  
2. Tech Quiz **or** Debugging  
3. BGMI **or** Table Tennis  
4. ICON Passport + People’s Choice  

### Mix C — Ambition year (only with strong manpower)
**Keep all core.**  
Extra:
1. Prompt Wars  
2. Data Dash  
3. CTF Lite  
4. Escape Room  
5. BGMI  
6. Short ICON Night closing

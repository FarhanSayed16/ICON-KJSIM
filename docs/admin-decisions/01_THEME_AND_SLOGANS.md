# Theme Families + Names + Slogans (Expanded)

## How to use this file

1. Pick **one family** (one world / one aesthetic).  
2. Pick **one name** from that family only.  
3. Pick **one slogan** that matches that name’s meaning.  
4. Keep posters, treasure-hunt clues, merch, and stage lines inside that same world.

**Do not mix families.**  
Example of wrong mix: *Chakravyuh* posters + *Pixel Rebellion* merch.  
Example of right match: Family = Magical Systems → name = *Mantraforge* → hunt clues = spells/runes → hackathon tracks named like “circles / grimoires.”
